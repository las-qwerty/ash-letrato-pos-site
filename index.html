Install guide

  • 1Download the APK onto the tablet, or copy it over via USB / Drive / Bluetooth.
  • 2Open it in the Files app → allow installs from that source when Android asks → tap Install.
  • 3If Play Protect shows an "unknown app" warning, tap Install anyway — the APK is signed.
  • 4Open the app → sign in → allow camera the first time you scan a barcode.
  • 1Download and run ASH LETRATO POS Setup.exe.
  • 2If SmartScreen asks, choose More info → Run anyway — normal for unsigned installers.
  • 3Next → Install → Finish. A desktop shortcut appears.
  • 4Open the app → sign in with the owner account or a staff PIN.
  • 1Open the POS web address in Safari — e.g. http://localhost:3100 or your shop's hosted address.
  • 2Tap Share (square with an up arrow).
  • 3Add to Home Screen → Add.
  • 4Launch from the Home Screen — it runs full-screen like a native app.

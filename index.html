Two-minute install

Pick your platform — each takes under two minutes.

1

Download the APK — straight onto the tablet, or copy it over via USB / Drive / Bluetooth.

2

Open it in the Files app → allow installs from that source when Android asks → tap Install.

3

If Play Protect shows an "unknown app" warning, tap Install anyway — the APK is signed with the ASH LETRATO certificate.

4

Open the app → sign in → allow camera permission the first time you scan a barcode.

Scan barcodes with the tablet camera — no scanner hardware needed. USB scanners also work via the search box.
1

2

3

Next → Install → Finish. A desktop shortcut appears.

4

Install guide

Each platform takes under two minutes.

  • 1

    Download the APK — straight onto the tablet, or copy it over via USB / Drive / Bluetooth.

  • 2

    Open it in the Files app → allow installs from that source when Android asks → tap Install.

  • 3

    If Play Protect shows an "unknown app" warning, tap Install anyway — the APK is signed.

  • 4

    Open the app → sign in → allow camera the first time you scan a barcode.

Scan barcodes with the tablet camera — no scanner hardware needed. USB scanners also work via the search box.

  • 1

    Download and run ASH LETRATO POS Setup.exe.

  • 2

    If SmartScreen asks, choose More info → Run anyway — normal for unsigned installers.

  • 3

    Next → Install → Finish. A desktop shortcut appears.

  • 4

    Open the app → sign in with the owner account or a staff PIN.

Data lives in the app's local storage on that PC. Export a backup from Settings → Data to move it elsewhere.

  • 1

    Open the POS web address in Safari — e.g. http://localhost:3100 or your shop's hosted address.

  • 2

    Tap Share (square with an up arrow).

  • 3

    Add to Home Screen → Add.

  • 4

    Launch from the Home Screen — it runs full-screen like a native app.

A native App Store build needs a Mac + Apple Developer account — planned once the demo is validated.
